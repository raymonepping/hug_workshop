# Historical workshop material

These documents describe the former HCP/Docker workshop and contain obsolete
commands, scoring and sample identities. They are preserved as historical reference,
not participant setup. Start with [current setup](../SETUP.md) and
[exercises](../EXERCISES.md).

The former organizer Terraform, agent/onboarding/drift scripts, token unwrapping,
registry build helper, Compose configuration and old environment examples were
retired after the local replacements passed. Their source remains in Git history.
Old connectors are retained here for reference only; they are not dependencies
or advertised supported database paths.
